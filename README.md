# React Vite Personal Website

A simple and responsive personal website built using **React.js, Vite, JavaScript, and CSS**.

This project was developed as part of the Module 14 Assignment to practice React component-based development, website structure, and CSS styling.

## 📌 Project Overview

The React Vite Personal Website is a basic frontend application consisting of multiple reusable components.

The website is organized into different sections to create a clean and structured user interface.

## ✨ Features

- **Header:** Website name/logo and navigation menu.
- **Hero Section:** Main heading, description, and call-to-action button.
- **About Section:** Information about the website or its developer.
- **Footer:** Copyright information and additional details.
- **Component-Based Structure:** Each website section is developed as a separate React component.
- **Custom Styling:** CSS is used to create an attractive and organized layout.

## 🧩 Website Components

### 1. Header Component

- Displays the website name or logo.
- Includes Home, About, and Contact navigation links.
- Provides the main navigation structure.

### 2. Hero Component

- Displays a prominent heading.
- Includes a short description.
- Contains a call-to-action button.

### 3. About Component

- Provides information about the website.
- Includes a heading and descriptive paragraph.
- Uses custom CSS styling.

### 4. Footer Component

- Displays copyright information.
- Includes additional footer details.
- Uses a separate background color and styling.

## ⚙️ Installation & Setup

### Prerequisites

- Node.js
- npm
- A code editor (VS Code recommended)

### 1. Clone the Repository

```bash
git clone https://github.com/hrithikdebnath37-max/react-vite-personal-website.git
```

### 2. Navigate to the Project Directory

```bash
cd react-vite-personal-website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser to view the website.
